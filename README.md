## What a reviewer can evaluate

- **Business processes:** how data and actions flow from a practical problem to a working interface.
- **Technical implementation:** TypeScript/React/Next.js, Supabase/PostgreSQL, Electron/SQLite and local-first workflows, depending on the project.
- **Decision-making:** input validation, status transitions, stock consistency, role constraints and explicit technical limitations.
- **Reproducible evidence:** the public Kepler source, documented StayOps and AlCaisse quality checks, and selected product screens.

I distinguish **a working build**, **a personal-use tool**, **a client project reported by its developer**, **a public demo** and **a production-certified service**. These terms are not interchangeable. Private client code and personal business data are not published by default.
